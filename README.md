# Batch Gradient Descent with Early Stopping — Multiclass Classification

- Implemented Batch Gradient Descent from scratch in Python/NumPy for multiclass classification on the Iris dataset.
- The project includes feature standardization, bias augmentation, softmax-based class probabilities, gradient computation, and validation-based early stopping to retain the best model parameters.
- Achieved a 3.33% error rate (96.67% accuracy) on the held-out test set.
